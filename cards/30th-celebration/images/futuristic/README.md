# Futuristic Rare

The gallery's Futuristic Rare filter contains only **157 (Mewtwo ex)** and
**158 (Mew ex)**, which are already part of the main set. These two copies make
the category browsable; the manifest lists the originals under `images/main/`.

The filter's `EN_1` tile is a 404 placeholder, not a card image. The three
remaining checklist entries are Basic Energy / Ultra Secret, not Pokémon
illustrations, and the gallery does not serve images for them.
